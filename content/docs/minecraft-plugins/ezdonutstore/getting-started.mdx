<Callout type="error">
Only Paper and Folia are officially supported. Use a full server restart for installs and updates.
</Callout>

## Requirements

| Requirement | Version |
|-------------|---------|
| Java | 21+ |
| Paper / Folia | 1.21+ |
| Required Plugins | None |
| Optional Plugins | PlaceholderAPI 2.11.6+ |

## Installation

1. Download the [latest plugin](https://github.com/Ez-Minecraft/EzDonutStore/releases) jar.
2. Place the jar in your server's `/plugins/` folder.
3. Start or fully restart the server.
4. Edit `/plugins/EzDonutStore/config.yml`.
5. Run `/store` in game to verify the store message.

## Notes

- Do not use `/reload` for installs or version updates.
- `%link_display%` becomes clickable store text.
- `%link_raw%` inserts the full store URL.
