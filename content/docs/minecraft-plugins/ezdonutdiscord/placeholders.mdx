---
title: PlaceholderAPI
description: Placeholder support in EzDonutDiscord
---

PlaceholderAPI support is optional. If PlaceholderAPI is installed and enabled in config, EzDonutDiscord can:

- Parse PlaceholderAPI placeholders inside plugin messages
- Register `%ezdonutdiscord_link_raw%`
- Register `%ezdonutdiscord_link_display%`

Placeholder parsing is applied for player senders when PlaceholderAPI is installed and `placeholderapi.enabled` is `true`.
