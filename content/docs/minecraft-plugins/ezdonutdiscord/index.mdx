<Callout>
EzDonutDiscord is a lightweight Paper and Folia plugin that gives players a polished <code>/discord</code> command with a clickable invite, optional action bar feedback, optional sound feedback, and PlaceholderAPI support.
</Callout>

## Features

- Paper and Folia support
- Clickable Discord invite in chat
- Configurable chat, hover, action bar, and reload messages
- Optional notification sound
- Optional PlaceholderAPI support
- Built-in PlaceholderAPI expansion
- Simple <code>/discord reload</code> admin command
