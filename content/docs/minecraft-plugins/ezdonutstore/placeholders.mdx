---
title: PlaceholderAPI
description: Placeholder support in EzDonutStore
---

PlaceholderAPI support is optional. If PlaceholderAPI is installed and enabled in config, EzDonutStore can:

- Parse PlaceholderAPI placeholders inside plugin messages
- Register `%ezdonutstore_link_raw%`
- Register `%ezdonutstore_link_display%`

Placeholder parsing is applied for player senders when PlaceholderAPI is installed and `placeholderapi.enabled` is `true`.
