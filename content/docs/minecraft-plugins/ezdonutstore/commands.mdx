## Player commands

### `/store`

- **Description**: Sends the configured store URL in chat.
- **Permission**: `ezdonutstore.store`

## Admin commands

### `/store reload`

- **Description**: Reloads `config.yml` and refreshes PlaceholderAPI integration.
- **Permission**: `ezdonutstore.reload`

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `ezdonutstore.store` | Allows use of `/store` | `true` |
| `ezdonutstore.reload` | Allows use of `/store reload` | `op` |
| `ezdonutstore.admin` | Grants all EzDonutStore permissions | `op` |
