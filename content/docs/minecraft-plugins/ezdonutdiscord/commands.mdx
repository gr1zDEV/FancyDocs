## Player commands

### `/discord`

- **Description**: Sends the configured Discord invite in chat.
- **Permission**: `ezdonutdiscord.discord`

## Admin commands

### `/discord reload`

- **Description**: Reloads `config.yml` and refreshes PlaceholderAPI integration.
- **Permission**: `ezdonutdiscord.reload`

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `ezdonutdiscord.discord` | Allows use of `/discord` | `true` |
| `ezdonutdiscord.reload` | Allows use of `/discord reload` | `op` |
| `ezdonutdiscord.admin` | Grants all EzDonutDiscord permissions | `op` |
