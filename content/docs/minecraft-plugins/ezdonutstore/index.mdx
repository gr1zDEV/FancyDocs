<Callout>
EzDonutStore is a lightweight Paper and Folia plugin that gives players a polished <code>/store</code> command with a clickable web store link, optional action bar feedback, optional sound feedback, and PlaceholderAPI support.
</Callout>

## Features

- Paper and Folia support
- Clickable store link in chat
- Configurable chat, hover, action bar, and reload messages
- Optional notification sound
- Optional PlaceholderAPI support
- Built-in PlaceholderAPI expansion
- Simple <code>/store reload</code> admin command
